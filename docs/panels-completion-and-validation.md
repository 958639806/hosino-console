## 完成的功能

| 功能 | 本轮结果 |
| --- | --- |
| 白名单 | 读取、预览和确认保存闭环；仅支持已存在的渠道来源/群来源与工具允许/禁止列表。校验配置版本、条目类型、生效规则；窗口内可预览，保存受保护，需要重启则不保存。 |
| 独立密钥 | 列表、新建、替换、清除。只显示元数据；清除前核对配置引用，使用中拒绝。值不回读、不出现在响应或审计原文，不自动重载或重启。 |

## 修复的问题

- 模型检测捕获请求开始时的认证世代，迟到的旧 401 不再使新登录失效。xAI 的请求路径、并发及检测方式保留；只纠正文案并显示网关/直连检测范围说明。
- 凭据预检、写入失败及成功警告统一清理本次值和常见编码；审计失败记录只保留受控错误码，日志页面也脱敏。
- 修正语音静默窗口提示、插件错误字段和失败状态识别。记忆界面明确自身限额、30 秒结果复用和后端向量缓存的区别。
- 向量缓存随 embedding 配置与凭据变化隔离；拒绝异常向量、畸形上游结果，安全处理配置与上游错误。
- QQ 撤回增加请求超时、账号凭据选择、凭据变更及 401 缓存失效。只撤回能明确归属的回执；文本有歧义时拒绝，避免撤回其他消息。
- 同会话重新生成互斥，防止重复回退和发送；回退成功但发送失败时明确提示刷新检查。
- 保留原会话分组、压缩、重置、删除和文件编辑器遮罩/未保存确认。白名单预览与应用使用实际提交快照，等待期间的新编辑继续保留。
- 测试使用仓库相对路径、临时资源和提前注册的清理，移除对旧 staging 工作目录的依赖；正式入口同时运行原稳定回归与新增测试。
- 使用 `fileURLToPath` 解析应用目录，修复部署路径含空格时静态资源和运行数据定位错误；实际 HTTP 测试在含空格目录运行。

## 部署与验证边界

- 本轮没有访问生产 QQ、Qdrant、供应商或真实 OAuth 账号。用户已确认原快照 xAI 实机检测正常；本轮以保留该行为并做模拟回归为准。
- 网关 RPC 签名已核对 `openclaw@2026.9.8` 发布源码；目标主机仍需验证其实际插件、认证方式、回调可达性及权限。网页向导不保证所有第三方供应商都提供远程登录能力，入口由网关能力决定。
- 静默窗口延续既有保护范围，新增配置/密钥/认证写入接入同一保护。取消登录属于清理，可在窗口内使用；不会自动撤销已完成授权。
- 白名单仅编辑支持的已有数组，未开放任意配置、自动创建权限项或自动重启。配置中没有可编辑字段时会显示空列表。
- 密钥引用核对基于当前网关配置；外部进程同时改配置或其他服务的隐式引用无法由控制台完全覆盖。旧密钥不保留。代码回滚不会恢复外部配置、凭据或授权。
- 回滚使用目标标签的完整源码、依赖及匹配数据，不混装新旧模块。流程见 [发布与回滚](releases.md)。
