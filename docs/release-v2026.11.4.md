# v2026.11.4 更新说明

发布日期：2026-11-03（新加坡时间）。本版以已部署的 `v2026.11.3.7` 快照为功能和界面基线，合并两轮候选版本的补全与修复；作为独立新版本发布，保留旧标签、旧 Release 和旧附件。

## 新增与补全

1. **白名单配置闭环**：读取已有渠道/工具权限列表，编辑后先预览差异，再确认保存；检查配置版本、条目类型和生效规则，需要重启时不保存。
2. **独立密钥管理**：支持新增、替换、引用检查后的清除；旧值不回读，清除前检查当前配置，使用中拒绝删除。
3. **OAuth/设备登录和账号排序**：按网关声明的能力提供真实分步授权向导，支持回答、等待和取消；流程绑定控制台会话，超时清理，排序核对完整账号集合与配置锁。
4. **OpenClaw 原生插件中心**：入口为“更多 → 能力与任务 → 插件中心”，提供搜索筛选、版本与来源、组件及配置详情、脱敏差异预览、复制和下载变更单。原有插件/技能状态页保留。

## 修复

- 模型检测捕获请求开始时的认证世代，迟到的旧 401 不再使新登录失效。
- 凭据成功警告和失败提示清理本次值及常见编码；审计只记录受控错误，日志页面也做脱敏。插件配置、schema 和变更单不回显密钥。
- embedding 端点、模型、维度或凭据变化时隔离缓存；验证向量和上游响应，异常返回安全提示。
- QQ 撤回增加请求超时、正确账号凭据选择和缓存失效；只使用能明确归属的回执，歧义时拒绝，防止撤回其他消息。
- 同会话重新生成互斥，防止重复回退和发送；失败时明确提示当前状态。
- 修正语音静默窗口提示、插件失败状态/详情，以及记忆搜索缓存和限额说明。
- 配置预览使用提交快照，等待期间的后续编辑继续保留；新面板处理迟到响应和导航归属。
- 修复部署路径含空格时资源/数据定位，以及快照测试依赖绝对路径和失败清理的问题。

## 保留的行为与限制

- **xAI 检测路径和并发方式保持原样**；保留快照全屏文件编辑器、简化会话设置和原有操作流程。
- **没有引入 AstrBot 兼容服务、Python 常驻进程或第二套机器人框架**。未来选定插件时再重写为原生扩展，并逐项验证。
- 插件中心当前默认只查看、预览和导出维护变更单，不直接安装、启停、卸载、重载或写入第三方插件配置。普通命令插件的生命周期变化也可能重连 QQ，不能把“热更新”当作“不影响 QQ”。
- 原生包候选仅检查标识格式，尚未下载、验证包内容或验证兼容性。密钥字段只显示设置状态；变更单不是可直接执行的安装脚本。
- 白名单、密钥和认证写入沿用静默窗口保护；取消登录仍可清理待完成向导。代码回滚不会恢复外部密钥、配置、账号顺序或已完成授权。

## 下载与安装

附件：`hosino-console-v2026.11.4.tar.gz`、`hosino-console-v2026.11.4.zip`、`hosino-console-v2026.11.4-SHA256SUMS.txt`。
