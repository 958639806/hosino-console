## 原 11 项问题的处理

| 原问题 | 修复与回归 |
| --- | --- |
| 异常 URL 导致后端退出 | URL 解析位于错误处理内，非法地址返回 400；原始未认证 HTTP 请求不再使进程退出。 |
| CLI 持久化失败卡住或抛出未捕获异常 | 持久化前安装终止监听；启动、流式和退出失败统一收尾，清理自有占位并停止自有进程，迟到事件不影响新任务。 |
| 保存期间继续编辑导致丢稿 | 使用实际提交快照作为已保存基线，输入框保持可编辑；后续输入仍需保存，撤销回提交快照也不会误报。 |
| 新建任务/导入表情入口消失 | 保留原按钮节点、原事件绑定及原表单，只移除重复标题和通用控件；移动端和桌面端均实际执行提交/导入。 |
| 401 后旧编辑器挡住登录页 | 暂存原 DOM 和草稿，认证失效期间不暴露或遮挡登录页，重新认证后恢复原编辑器、焦点与轮询。 |
| 登出失败假显示成功 | 网络或 HTTP 错误保留当前页面及草稿，显示原有错误提示；成功登出才清理旧界面。 |
| 群报投递期间重生成导致图文混用 | 生成和投递按报告 ID 共用互斥锁，投递先固定图文快照，冲突请求返回 409。 |
| 409 force 请求仍重置队列 | 先取得锁再修改队列，被拒绝请求不改变任何发送状态。 |
| Tab 焦点进入弹层背景 | 顶层弹层内循环 Tab/Shift+Tab，背景 inert；嵌套关闭后恢复焦点和原 inert 状态。 |
| 过期附件仍可直接下载 | GET 即时检查 TTL，在清理尚未执行时也返回 404；正常文件和删除操作不受影响。 |
| 无效 JSON 返回 502 | 改为 400；请求大小按字节限制，跨块 UTF-8 字符正确解析，异常/中断请求能结束处理。 |

## 修复后定向复查额外发现并处理的边界

- **旧 401 迟到**：旧请求在新登录完成后才返回 401，会再次挂起界面。API 层增加认证世代，fetch、XHR、SSE 和试听请求只对所属世代通知失效。
- **跨失败提交混用图片**：新图片成功、JSON 落盘失败时，旧 JSON 可能仍指向被覆盖的图片。改为每次生成独立、不可变图片文件名；提交失败保留原图文，并仅清理确认未被已提交记录引用的新孤立图片。
- **重试/强制重发混用**：已经发出任一步的群报不能以同一 ID 重新生成。强制重发先持久化新批次，普通失败重试复用该批次；用幂等缓存和丢失确认模拟验证了实际重发和重试不重复。
- **自动批次的旧列表**：等待前一项网关响应后，重新读取后续报告，避免把人工重生成的新报按旧 schedule 快照自动投递。

图片 API URL 不变，读取已提交 JSON 中严格限定于同报告的图片名，兼容旧 `id.png` 和新 `id--随机值.png`，不接受目录穿越或跨报告路径。该图片 URL 使用 `no-store`。
