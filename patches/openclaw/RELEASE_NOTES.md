# hosino-console 配套补丁 patches-2026.11.13（草稿）

> 某芙芙ai再这么高冷，就不帮你修了

有人反馈装了控制台用不了：表情包、语音、拟人化、私聊陪伴、撤回这些面板没反应。原因是这些功能要靠 OpenClaw 那边的插件和补丁才能生效，以前的版本只发布了控制台本身。这次把补丁一起发出来。

## 包含

- **两个自有插件**（整目录复制）：`qq-group-followup-gate` v2.4.1、`qq-group-owner-guard` v1.2.0。
- **qqbot 2.0.4 补丁**（必装）：表情/语音标签发送、表情和语音参数、发送结果回执、撤回需要的送达记录、私聊陪伴。
- **workspace 脚本**：表情包管理和生成、语音合成、拟人化数据脚本。
- **tools-effective 缓存补丁**（建议装）：修控制台“工具”页让网关每分钟卡一次、控制台断线的问题。附带按常量名匹配的脚本版。
- **选装**：OpenClaw 核心全量补丁（103 个文件）、codex、mem0、mem0ai 补丁，主要是 QQ 侧的延迟和行为优化。
- `install.sh`：默认只检查，加 `--apply` 才写入，每次都先备份，不会重启网关。另附回滚步骤。

## 适用版本

只适用于 **OpenClaw 2026.9.8 + qqbot 2.0.4**。插件和语音脚本直接引用了 2026.9.8 带哈希的内部文件，在 2026.11.3 等新版上会加载失败。用新版的话，先装回 2026.9.8：`npm i -g openclaw@2026.9.8`。

## 注意

- 原作者自己的 QQ id、群 id、群友名字、主机路径都换成了 `__HS_XXX__` 占位符，安装时用 `tools/configure.py` 和你自己的 `my-ids.json` 填进去。不填的项对应功能不生效，不会报错。
- 不包含任何 key、人设（AGENTS.md）、记忆、表情包图片和运行时数据。Fish、豆包、MiMo 的 key 请用环境变量或 secret store 配置。
- 已验证：补丁打到 npm 原版包上、再填回原作者的值，结果和线上运行的文件逐字节一致；安装和回滚在模拟目录里跑通。还没有在全新机器上实测网关和 QQ，遇到问题请提 issue。
